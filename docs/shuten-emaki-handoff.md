# ゲーム企画引き継ぎ書：酒呑童子絵巻ゲーム

## 1. ゲームの基本コンセプト

題材は、実在する日本の絵巻「酒呑童子絵巻」。

目指すのは、単に大和絵風のキャラクターが登場するアクションゲームではない。

**「酒呑童子絵巻そのものがゲームになった」** という体験を実現する。

プレイヤーは、絵巻を鑑賞するだけでなく、その中を移動し、戦い、物語に参加する。

## 2. グラフィックの方向性

最重要方針は、大和絵そのものが動き出したように見せること。

- 現代的なアニメキャラクターを大和絵風の背景に配置するのではない。
- 実在する絵巻の人物・鬼・建物・衣装・彩色・筆線・構図を視覚的な基準とする。
- 人物が動くときも、絵巻の筆線や彩色の質感を可能な限り維持する。
- 滑らかな現代アニメ風の動きよりも、静止していた絵が生命を得たような動きを重視する。
- 絵巻の平面的な構図や、人物の大小、雲、余白、場面構成をゲーム表現に活用する。

公開版では、作品画像の利用条件や所蔵者の規約を考慮し、必要に応じて実物に極めて近い新規制作画像を使用する。

## 3. ゲーム進行方向

ゲーム進行方向は右から左。絵巻を読み進める方向そのものに合わせる。

- プレイヤーは基本的に右から左へ進む。
- 絵巻の背景も右から左へ展開する。
- カメラやステージ構成も、この進行方向を前提に設計する。
- プレイヤーの身体・顔・武器の向きも、左方向への進行と戦闘に整合させる。
- ゲーム画面を見たときに、絵巻を右から左へ読み進めている感覚を生み出す。

単に画面を左右反転させるのではなく、人物の向きや場面の構図も含めて、右から左への進行が自然に見えるようにする。

## 4. ゲーム形式

基本は、絵巻の中を進んで戦う2D横スクロールアクションを想定する。

ただし、一般的な横スクロールゲームの背景に大和絵を貼り付ける方式にはしない。

- ステージそのものを、横に長く連続する一枚の絵巻として扱う。
- 場面転換は、通常のゲームのような唐突な画面切り替えではなく、絵巻が続いていく感覚を重視する。
- プレイヤーの移動と、絵巻を読み進める動作を一体化させる。
- ゲームの進行に合わせて、絵巻の世界が少しずつ現れていく構成を目指す。

## 5. 異時同図をゲームシステムにする

絵巻表現の重要な特徴である異時同図を、単なる見た目の演出ではなく、ゲームの仕組みにする。

異時同図とは、異なる時間に起きた出来事を、一つの画面・構図の中に同時に描く表現である。

ゲーム内での構想：

1. プレイヤーが特定の場所で行動する。
2. そのときの姿や行動を記録する。
3. 後のプレイで同じ場所に来ると、過去のプレイヤーの姿が絵の中に残っている。
4. 現在のプレイヤーと過去のプレイヤーが、一枚の絵の中に共存する。
5. 将来的には、過去の行動が攻撃・仕掛け・ルート選択などに影響する仕組みへ発展させる。

これにより、プレイヤーが遊んだ時間そのものが絵巻の一部になる。

クリアだけでなく、ゲームオーバーまでを絵巻に記録する可能性もある。

## 6. プレイヤーの行動が絵巻を作る

最終的には、プレイヤーが進んだ場所や取った行動が、絵巻の中に記録されていく仕組みを目指す。

ゲームを遊ぶことは、単に用意されたステージを攻略することではない。プレイヤー自身が、一枚の絵巻の中に新しい出来事を描き加えていくことになる。

プレイ終了後には、ゲーム中の行動が描き込まれた絵巻を振り返れる構想とする。

## 7. 企画の中心となる体験

- 大和絵の中でゲームをする。
- 絵巻の人物が本当に動き出したように感じる。
- 右から左へ絵巻を読み進めながら冒険する。
- プレイヤー自身が絵巻の物語に参加する。
- 過去と現在の行動が一枚の絵の中に共存する。
- 自分のプレイが絵巻の一部として残る。

## 8. 最終目標

「酒呑童子絵巻を題材にしたゲーム」ではなく、**「酒呑童子絵巻そのものがゲームになった」** 作品を作る。
