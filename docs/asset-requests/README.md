# アセット発注書（API キー無し運用）

画像・スプライト・3D 素材が必要になったとき、Claude は `/asset-gen`（有料 API）を使わず、
ここに**発注書**を書く。人間が好きな画像 AI で作成し、指定パスに置く。

## 流れ
1. Claude が `docs/asset-requests/<アセット名>.md` を `TEMPLATE.md` から作る
2. Claude が**仮素材**（単色・簡易図形）を同じファイル名で置き、ゲームは止めずに進める
3. 人間が発注書のプロンプトで画像を作り、指定パスに**同名で上書き**する
4. Claude が差し替え後の画像を読み込んで見た目を確認し、必要なら発注書を更新して再発注する

## ルール
- 全アセットの冒頭に `STYLE.md` の共通スタイルを差し込み、画風をそろえる
- 発注書の「状態」を `未発注` → `仮素材で進行中` → `納品済み` と更新する
- 仮素材はコードで生成し、ファイル名・サイズ・透過の有無は本番と同じにする
- 外部素材（CC0 など）を使った場合は出典とライセンスを `CREDITS.md` に記録する

## ファイル
- `STYLE.md` … 共通スタイルガイド（画風・色・線・光）
- `TEMPLATE.md` … 発注書のひな形
