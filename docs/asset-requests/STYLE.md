# 共通スタイルガイド — 酒呑童子絵巻アクションゲーム

出典: `CLAUDE_CODE_RESTART_SPEC.md` §1・§4・§6。このガイドは指示書の要約であり、**独自の解釈は加えない**。
具体的な色コード・線の太さなど、基準画面の実物がないと決められない項目は **R1（絵巻資料の基準化）で確定**する。それまでは「未確定」のままにする。

## 1. 目指すもの
実在する「酒呑童子絵巻」そのものが動き出し、絵巻の世界を操作しているような体験。
単に和風のゲームを作るのではない。

## 2. 守ること
- 絵巻の**大和絵**としての造形を維持する
- ゲームの進行方向は**右から左**
- 絵巻の平面的な構図、筆線、岩絵具を思わせる色彩、雲、余白、人物の簡略化を尊重する
- 3 つの資料の画風を混ぜて平均化しない

## 3. 避けること
- 現代的なアニメ、漫画、RPG、一般的な和風ゲームの表現
- キャラクターを過剰に格好よく、美形に、筋肉質に描く
- 3D 的な陰影、光沢、派手なエフェクト
- キャラクターだけが背景から浮いて見えること

## 4. 資料の優先順位
| 優先 | 資料 | 役割 |
|---|---|---|
| 1 | サントリー本《酒伝童子絵巻》 | 全体の基準（画風・色彩・構図・人物の簡略化・衣装・甲冑・武器・雲・余白） |
| 2 | 東京国立博物館《酒呑童子絵巻》（孝信本） | 源頼光・四天王など武者表現の補足 |
| 3 | 《土蜘蛛草紙絵巻》 | 古い武者の顔・身体の簡略化・姿勢・衣装・武器の補足 |

URL は `CLAUDE_CODE_RESTART_SPEC.md` §4 を参照。第 2・第 3 は必要な箇所だけ参照する。

## 5. 最終判断基準
> このキャラクターを基準となる酒呑童子絵巻の画面に置いたとき、もともと絵巻に描かれていた人物のように見えるか。

見えない場合は修正する。

## 6. 画像素材の共通仕様（§6）
- 背景が本当に透過されている
- キャラクターがフレーム外にはみ出していない
- フレームごとのサイズと基準位置が統一されている
- 頭身・顔・装備・衣装の模様が一貫している
- フレーム番号と動作順が正しい
- 武器が不自然に変形していない
- 余計な文字・枠線・説明図が混入していない
- ゲームで使う実際の画像形式・サイズに変換できる
- **説明用のコンセプトシートと、ゲーム用スプライトシートを区別する**

## 7. 未確定（R1 で確定）
- 基準画面（サントリー本のどの場面か）
- 色の基準（岩絵具の色味）、輪郭線の太さ・質感
- 人物の頭身、画面内での人物の大きさ
- 画像の標準サイズ・余白・基準位置（R3 で素材仕様書として確定）
