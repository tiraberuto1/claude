## 発注前に知っておくこと（仮決定。変えたい場合は言う）
| 項目 | 仮決定 | 理由 |
|---|---|---|
| 持ち方 | 両手で柄を握る | 斬り下ろしは両手のほうが自然。絵巻での扱いは未確認 |
| 刃の向き | 刃（切れる側）が下、峰（背）が上 | 指示書 §5.4「刃は基本的に下向き」を、太刀の通常の持ち方と解釈した。別の意味なら要確認 |
| 効果 | 斬撃の光・軌跡は描かせない | 指示書 §1・§6。旧版では絵に焼き込まれて問題になった。必要ならゲーム側で付ける |
| 並び順 | 構え→振りかぶり→斬り下ろし→残心 | 指示書の「1→2→4→3→5→6」は旧 6 コマ案に対する修正で、今回の 4 コマには当てはまらない |
| 画像 | 1536×1536 の透過 PNG、人物の背丈は高さの約 70%、足の裏は下から約 12% | 刀が大きくはみ出す姿勢でも収まる。コマ間の位置合わせは Claude Code が切り出して行う |
