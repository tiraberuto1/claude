添付画像は、源頼光が太刀を頭の上へ振りかぶっている全身の絵です。この絵を、下の「直してほしい1か所」だけ直してください。それ以外は、1画素も描き変えないつもりで、そのまま残してください。

■ 直してほしい1か所
腰の鞘をつかんでいる手（と、その手につながる腕）を消してください。
- 今の絵では、頭の上の2本の腕で柄を握っているのに、さらに画面の右側の腰で鞘をつかむ3つ目の手が描かれています。人物の腕は2本だけです。
- 腰の鞘をつかむ手と、その腕を消す。消した腕の袖は、体の後ろに回って隠れた形にし、袖だけが体の横に垂れ下がらないようにする。肩の大袖（鎧の肩）は、そのまま残す。
- 鞘は、帯に差したままで、手が触れていない状態にする。鞘の位置・向き・形・金の文様は変えない。
- 手を消した後の、衣・鎧・帯のつながりは、自然に見えるようにする。

■ 変えないもの（そのまま残す）
- 頭の上の2つの手と、太刀（刀身の反り・長さ・角度・鍔・柄・位置）
- 顔立ち・表情・髪型・簪・体と顔の向き
- 脚の開き方・踏み込み・足・草鞋・臑当
- 鎧（縅の黒と赤の縞・胸の金の板・大袖）・衣の花文様・袴の文様・帯
- 画面の構図・人物の位置と大きさ・画風・色・質感・背景
- 新しい要素（効果・文字・影・他の人物）は足さない

■ 納品後の検収条件（こちらで確認します）
1. 人物の腕が2本だけで、手が頭の上の2つだけである
2. 腰の鞘に手が触れておらず、鞘が帯に差さっている
3. 「変えないもの」が元の絵のままである
4. 袖が体の横に垂れ下がっていない
