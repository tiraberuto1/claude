# 振りかぶり 修正プロンプト v2（腕が 3 本になる問題・別の方法）

v1（「余分な手を消して」）は直らなかった。直す指示は「消す」ではなく、**原因（鞘に手が伸びる）をなくす**方向に変える。
添付: 前回の絵（元画像）。**この絵の手と刀以外は変えない。**

```
添付の絵を修正してください。直すのは 1 か所だけです。

■ 直すところ
人物の腕が 3 本に見えています。左腰の鞘をつかんでいる手とその腕が余分です。
修正のやり方を変えます。「手を消す」のではなく、「鞘を絵から取り除く」ことで解決してください。

- 腰の鞘（さや）は、絵から完全に取り除く。帯の位置にも、体の後ろにも、鞘は描かない
- 鞘をつかんでいた手とその腕・袖も取り除く
- 取り除いたあとは、帯と衣の続きの絵で自然につなぐ（穴や空白を残さない）
- 腕は 2 本、手は 2 つだけ。両手とも、頭の上の刀の柄を握っている

■ 変えないもの（そのまま残す）
- 頭上に振りかぶった両手と、抜いた刀（柄の握り、刃の長さ・向き・刃が下に向く角度）
- 顔、髻と簪、体と顔の斜め左向き
- 脚、足、草鞋の位置と開き
- 鎧、衣、袴の色と文様
- 人物の大きさ、位置、構図
- 平らな塗り、線の太さ、絵巻風の画風
- 背景（透明または無地）

■ 加えないもの
- 新しい手、腕、鞘、持ち物、背景、文字、効果線

■ 検収条件
1. 腕が 2 本、手が 2 つ（両手とも頭上の柄）
2. 鞘がどこにも描かれていない
3. 帯と衣に穴や継ぎはぎがない
4. 「変えないもの」が元の絵のまま
