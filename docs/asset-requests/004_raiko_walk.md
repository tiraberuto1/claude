## 貼り付け用プロンプト

```
ゲームの主人公「源頼光」の「歩く」動きを、6コマの画像として描いてください。
添付画像は次のとおりです。
1. 源頼光の基準立ち絵（この人物の顔・髪型・装備・衣装・体つきを、そのまま保ってください）
2. 絵巻の武者たち（線と塗りの見本。立ち絵の画風はこれに合わせてあります）
3. （添付があれば）歩いている人物の見本。脚の運びだけを参考にしてください。顔や衣装は写さないでください。

■ 発注名
酒呑童子絵巻アクションゲーム「源頼光」WALK（歩行）6コマ

■ 用途
プレイヤーが左へ進むときに、画面上で繰り返し再生する歩く動きです。ゲームでは 1→2→3→4→5→6→1… の順に繰り返します。人物はゲーム側で画面の中を動かすので、絵の中では前へ進まず、その場で足踏みする形（足だけが前後に入れ替わる形）にしてください。

■ 最重要：基準立ち絵を写さないこと
添付1は「立って静止している姿」です。6コマはどれも、立ち姿のコピーではなく、歩いている途中の姿にしてください。
- 変えるのは「脚の位置」「腕のふり」「体の上下のわずかな動き」だけです。
- 変えないのは、顔立ち・髪型・装備・衣装の色と文様・太刀・体つき・人物の大きさです。
- 脚の位置は、下の「6コマの動き」のとおり、コマごとにはっきり違うものにしてください。6コマのうち両脚が立ち姿と同じ位置のコマがあってはいけません。

■ 向き
- 人物は画面の左へ歩いています。添付1と同じ、体と顔をそろえた斜め左（4分の3）の向きで、6コマとも向きを変えないでください。
- 顔だけが別の方向を向く形にはしないでください。

■ 6コマの動き（歩きの1周期。左脚＝画面の左側にある脚、右脚＝画面の右側にある脚）
- コマ1【踏み出し】左脚を前（画面の左）へ大きく踏み出し、かかとが地面に着く。右脚は後ろにあり、つま先で地面を蹴っている。体は少し低くなる。
- コマ2【体重が乗る】体重が前の左脚に乗り、膝が少し曲がる。右脚は後ろから離れかけ、つま先だけが地面に触れている。体は最も低い。
- コマ3【通りすぎ】右脚が後ろから前へ振り出され、左脚のそばを通る。両脚が近づき、体は最も高い。
- コマ4【踏み出し・逆脚】右脚を前（画面の左）へ大きく踏み出し、かかとが地面に着く。左脚は後ろにあり、つま先で地面を蹴っている。体は少し低くなる。
- コマ5【体重が乗る・逆脚】体重が前の右脚に乗り、膝が少し曲がる。左脚は後ろから離れかけ、つま先だけが地面に触れている。体は最も低い。
- コマ6【通りすぎ・逆脚】左脚が後ろから前へ振り出され、右脚のそばを通る。両脚が近づき、体は最も高い。
- 腕：太刀は鞘に収めたまま腰に佩き、右手は柄に添えたままにする。左腕は歩幅に合わせて、前後に小さく振る。
- 体の上下の動きは、背丈の1〜2%以内。袖・草摺・房は、歩きに合わせてわずかに揺れる程度にする。
- 歩幅は小さめにし、絵巻の人物らしく落ち着いた歩きにする。走る・跳ぶ形にしない。

■ 画風の条件（添付1・2から変えない）
- 実在する「酒呑童子絵巻」の大和絵としての造形。墨の細い輪郭線、岩絵具を思わせる平らな色。
- ひび割れ・モザイク状の質感、陰影・光沢・グラデーション・エフェクトは入れない。
- 現代的なアニメ・漫画・RPG・一般的な和風ゲームの絵にしない。

■ 画像仕様
- 形式：PNG（RGBA・背景透過）。人物以外は完全に透明にする。透過を表す市松模様・白背景・影・地面・土ぼこりは描かない。
- 大きさ：1536×2048px の1枚の画像。横3列×縦2段の格子に6コマを並べる。
  - 1段目は左から コマ1・コマ2・コマ3、2段目は左から コマ4・コマ5・コマ6。
  - 画像を横に3等分、縦に2等分した、1区画 512×1024px の中に、1コマずつ収める。区画からはみ出さない。
- 6コマとも、人物の大きさ（頭から足まで）を同じにする。人物の背丈は、区画の高さの約80%（約820px）にする。
- 足が地面に着いているときの足の裏は、6コマとも同じ高さにそろえる。通りすぎのコマで後ろ脚が浮くとき以外は、足の裏を同じ水平線に置く。
- 人物の体の中心は、どの区画でも区画の横の真ん中にそろえる（歩きの途中で体全体が左右にずれないようにする）。
- 区画の上下左右には、それぞれ6%以上の余白を設ける。頭・足・太刀の先が切れないようにする。
- 区切り線・枠・コマ番号・文字は描かない。

■ 禁止事項
- 文字、ロゴ、署名、枠線、区切り線、コマ番号、説明図、色見本、背景、地面の影、透過を表す市松模様
- 立ち姿のコピー、顔だけが別の方向を向く形、真横の横顔
- 顔立ち・髪型・装備・衣装の色と文様・太刀・体つきを、添付1から変えること
- 走る・跳ぶ・大股で歩く形、誇張した動き

■ 納品後の検収条件（こちらで確認します）
1. 画像にアルファチャンネルがあり、人物以外が完全に透明である
2. 1536×2048px で、6コマが横3×縦2の格子に並び、各コマが 512×1024px の区画の中に収まっている
3. 6コマとも体と顔がそろって斜め左を向いている
4. 6コマで、人物の大きさと足の裏の高さがそろっている。体の中心が区画の真ん中にある
5. 脚の位置が上の「6コマの動き」どおりで、コマ1〜3とコマ4〜6で前に出る脚が入れ替わっている。立ち姿のコピーのコマがない
6. 顔・髪型・装備・衣装・太刀が添付1と一致している
7. 1→2→3→4→5→6→1 と繰り返して、不自然に跳ねたり、ちらついたりしない
8. 文字・枠・区切り線が混入していない

■ 納品方法
PNG画像を1枚提出してください。
```
