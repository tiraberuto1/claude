## なぜ IDLE だけ先に発注するか
ChatGPT は MASTER の 2 回とも「胴は正面・顔は左」で描いた。モーションは体ごと左を向く必要があるため、まず小さい IDLE で「全身を左向き」が描けるかを確かめ、検収に合格してから WALK を発注する。

## 貼り付け用プロンプト

```
添付の画像は、ゲームの主人公「源頼光」の基準立ち絵（MASTER）です。この人物の「待機」の動きを、3コマの画像として作ってください。
顔立ち・髪型・装備・衣装の色と文様・太刀・体型は、添付の基準立ち絵から変えないでください。

■ 発注名
酒呑童子絵巻アクションゲーム「源頼光」IDLE（待機）3コマ

■ 用途
プレイヤーが操作していないときに、画面上で繰り返し再生する待機の動きです。ゲームでは 1→2→3→2→1… の順に繰り返します。

■ 向き（最重要）
- 全身を左向きにしてください。顔・胸・腰・足先をすべて画面の左へ向けた、横向きから斜め左向きの立ち姿です。
- 基準立ち絵は胴が正面を向いていますが、ゲーム中の人物は進行方向（左）を向くため、待機では体ごと左を向かせてください。
- 顔だけが左を向き、胴が正面のまま、という形にはしないでください。

■ 3コマの動き
- 動きはごくわずかにしてください。絵巻の人物がかすかに動いている程度で、呼吸や揺れを誇張しないでください。
- コマ1：基本の立ち姿。太刀は鞘に収めたまま、基準立ち絵と同じく手に持つ。
- コマ2：かすかに息を吸った姿。肩と大袖がわずかに上がる（背丈の1〜2%程度）。
- コマ3：コマ2から、袖・房・袴の裾がわずかに揺れる。
- 3コマとも、足の位置・立ち位置・人物の大きさは変えないでください。

■ 画風の条件（基準立ち絵から変えない）
- 実在する「酒呑童子絵巻」の大和絵としての造形。平面的な構図、筆線、岩絵具を思わせる平らな色彩、人物の簡略化。
- ひび割れ・モザイク状の質感は入れない。輪郭線をはっきりさせる。
- 現代的なアニメ・漫画・RPG・一般的な和風ゲームの絵にしない。過剰に格好よく・美形に・筋肉質にしない。
- 3Dのような陰影・光沢・エフェクトは描かない。

■ 画像仕様
- 形式：PNG（RGBA・背景透過）。人物以外は完全に透明。透過を表す市松模様・白背景・影・地面・土ぼこりは描かない。
- 1枚の横長画像（1536×1024px）に、3コマを左から順に横一列で並べる（左端がコマ1、中央がコマ2、右端がコマ3）。
- 画像を横に3等分した各区画（幅512px）の中に1コマずつ収める。区画からはみ出さない。
- 3コマとも人物の大きさを同じにし、足の裏の高さ（接地の位置）を同じ高さにそろえる。
- 各区画の上下左右に余白を設け、頭・足・太刀の先が切れないようにする。
- 区切り線・枠・番号・文字は描かない。

■ 禁止事項
- 文字、ロゴ、署名、枠線、区切り線、コマ番号、説明図、色見本、背景、地面の影、透過を表す市松模様
- 顔立ち・髪型・装備・衣装の色と文様・太刀・体型を基準立ち絵から変えること
- 誇張した動き、エフェクト

■ 納品後の検収条件（こちらで確認します）
1. 画像にアルファチャンネルがあり、人物以外が完全に透明である
2. 3コマが横一列に並び、各コマが幅512pxの区画の中に収まっている
3. 3コマとも全身が左向きで、顔だけが別の方向を向いていない
4. 3コマで人物の大きさと接地の高さがそろっている
5. 動きがごくわずかで、1→2→3→2 と繰り返して不自然に跳ねない
6. 造形が基準立ち絵と一致している
7. 文字・枠・区切り線が混入していない

■ 納品方法
PNG画像を1枚提出してください。
```
