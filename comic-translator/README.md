# フキダシ翻訳（Android）

電子書籍アプリで開いたアメコミの吹き出しを読み取り、英語のセリフの上に日本語訳を重ねて表示する Android アプリです。
書籍アプリそのものには手を加えず、画面の取り込み（MediaProjection）と、他のアプリの上に重ねる窓（オーバーレイ）で動きます。

## しくみ

1. **取り込み** — `CaptureService` が画面を仮想ディスプレイに映し、最新のフレームを保持する。取り込む瞬間だけ自分の窓を隠す。
2. **文字認識** — ML Kit のテキスト認識（端末内・ラテン文字）で行ごとの文字と位置を得る。
3. **吹き出しの組み分け** — `BalloonGrouper`。アメコミの写植は「全大文字・中央揃え・詰まった行間」なので、字の高さが近く、上下の隙間が字の高さ以内で、中心が揃った行を 1 つの吹き出しにまとめる。大きな擬音（SFX）とセリフは字の大きさの違いで分ける。
4. **英文の整え** — `ComicText`。行末ハイフンで分かれた単語をつなぎ、`--` をダッシュに、全大文字を文頭大文字にする（機械翻訳は全大文字だと質が落ちるため）。
5. **翻訳** — 2 種類から選ぶ。
   - **端末内**（ML Kit 翻訳）：無料・オフライン。初回に英→日モデル（約 30MB）を取得。
   - **Claude**：ページの画像と吹き出し一覧をまとめて送り、話者や場面を見て口調を決めた訳を JSON で受け取る。OCR の読み違いも絵から補う。API キーが必要で、1 ページごとに料金がかかる。
6. **表示** — 吹き出しの地色（領域でいちばん多い明るさの色）で英文を塗りつぶし、日本語を `JapaneseLayout` で収まる最大の大きさに組む（行頭・行末の禁則処理つき）。

### 自動モード

600ms ごとに画面を縮小して比べ、訳文を出しているページから大きく変わったら（自分が描いた訳文の部分は比べない）訳文を消し、2 回続けて画面が止まったら翻訳し直します。

### 他アプリへのタッチを妨げないために

Android 12 以降は、他のアプリの上に不透明な窓を全面に重ねると、その下へのタッチが遮られます。
そのため訳文は吹き出しごとの小さな窓にしてあり、吹き出し以外の場所ではそのままページをめくれます。訳文をタップすると 2.5 秒だけ原文が見えます。

## 使い方

1. アプリを開き、「他のアプリの上に表示」を許可する。
2. 翻訳のしかたを選ぶ（Claude の場合は API キーを入力）。
3. 「開始」→ 画面の取り込みを許可 → 書籍アプリでコミックを開く。
4. 赤い「訳」ボタンで今のページを翻訳。もう一度押すと原文に戻る。長押しで終了。

## 制限

- **画面の取り込みを禁止している書籍アプリでは使えません。** 保護されたコンテンツは真っ黒に取り込まれるため、その場合は「取り込みが禁止されています」と表示します。
- 手書き風の特殊なフォントや、絵に溶け込んだ擬音は読み取れないことがあります。
- 横組みで表示します（アメコミの吹き出しは横長のため）。

## ビルド

```
./gradlew :core:test          # 吹き出しの組み分け・英文整形・組版・ページ送り検出・Claude 応答の解析
./gradlew :app:assembleDebug  # APK（Android SDK が必要）
```

Android SDK が見つからない環境では `:app` を外し、純 Kotlin の `:core` だけをビルドします。
GitHub Actions（`.github/workflows/fukidashi-android.yml`）がテストと APK のビルドを行い、APK を成果物として保存します。

| モジュール | 内容 |
|---|---|
| `core` | Android に依存しない処理。`BalloonGrouper` `ComicText` `JapaneseLayout` `PageChangeDetector` `ClaudeTranslator` |
| `app` | 画面の取り込み、ML Kit、オーバーレイ、設定画面 |
