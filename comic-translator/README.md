# フキダシ翻訳（Android）

電子書籍アプリで開いたアメコミの吹き出しを読み取り、英語のセリフの上に日本語訳を重ねて表示する Android アプリです。
**翻訳はすべて端末の中で行い、料金はかかりません。** 通信するのはモデルを最初に用意するときだけです。

書籍アプリそのものには手を加えず、画面の取り込み（MediaProjection）と、他のアプリの上に重ねる窓（オーバーレイ）で動きます。

## 翻訳のしかた

| | 端末内の機械翻訳 | 端末内の AI（LLM） |
|---|---|---|
| 仕組み | ML Kit 翻訳（英→日） | MediaPipe LLM Inference で Gemma 3n などを端末の GPU/CPU で実行 |
| 速さ | 1 ページ 1 秒前後 | 1 ページ数十秒（章の一括処理なら読むときは待たない） |
| 文脈 | なし | あらすじ・人名の訳語・口調・直前のセリフを踏まえて訳す |
| 準備 | 初回に約 30MB を自動取得 | モデルファイル（.task）を取り込む |

AI が番号を飛ばした行は一度だけ訳し直し、それでも欠けた行は機械翻訳で埋めます。

### 物語の文脈

作品ごとに次のものを端末に保存し、翻訳のたびにプロンプトに入れます（`StoryContext`）。

- 人名・地名の訳語（「Peter = ピーター」）。続きの章でも同じ表記になる
- 登場人物の口調のメモ（「軽口を叩く」「ぶっきらぼう」）
- 直前に訳したセリフ（会話の流れをつなぐ）
- これまでの章のあらすじ

### 章の一括処理

赤いボタンを長押し（または通知の「章を一括処理」）すると、

1. ユーザー補助サービス（`PageTurnService`）がスワイプかタップでページをめくりながら、各ページの文字と位置を読む。めくっても画面が変わらなくなったら章の終わり
2. 章全体のセリフから、AI があらすじと登場人物（訳語と口調）を抜き出す
3. それを添えて、12 個ずつまとめて訳す
4. ページの見た目の指紋（縮小画像）と訳文を結びつけて保存する（`PageLibrary`）

章の最初に戻って読むと、保存済みのページは OCR も翻訳もせずにすぐ訳文が出ます。

## 吹き出しの読み取りと表示

1. **取り込み** — 取り込む瞬間だけ自分の窓を隠す。
2. **文字認識** — ML Kit（端末内・ラテン文字）で行ごとの文字と位置を得る。
3. **組み分け** — `BalloonGrouper`。アメコミの写植は「全大文字・中央揃え・詰まった行間」なので、字の高さが近く、上下の隙間が字の高さ以内で、中心が揃った行を 1 つの吹き出しにまとめる。
4. **英文の整え** — `ComicText`。行末ハイフンで分かれた単語をつなぎ、全大文字を文頭大文字にする。
5. **表示** — 吹き出しの地色で英文を塗り、日本語を `JapaneseLayout` で収まる最大の大きさに組む（禁則処理つき）。訳文は吹き出しごとの小さな窓なので、吹き出し以外の場所ではそのままページをめくれる。

自動モードでは、訳文を出しているページから画面が大きく変わったら訳文を消し、止まったら訳し直します（自分の訳文の部分は比べない）。

## 使い方

1. 「他のアプリの上に表示」を許可する。章の一括処理を使うなら、ユーザー補助の「フキダシ翻訳のページめくり」もオンにする（ストア外から入れた場合は、アプリ情報のメニューから「制限付き設定を許可」が必要）。
2. 翻訳のしかたを選ぶ。AI を使うなら、MediaPipe 用の Gemma 3n（E2B か E4B、int4 の `.task`）を Hugging Face などで利用規約に同意してダウンロードし、「モデルファイルを取り込む」で選ぶ。目安は E2B で空きメモリ 3GB、E4B で 4GB。
3. 作品名を入れる（訳語と文脈は作品ごとに分かれる）。
4. 「開始」→ 画面の取り込みを許可 → 書籍アプリでコミックを開く。
5. 「訳」ボタンで今のページを翻訳、長押しで章の一括処理。終了は通知の「停止」。

## 制限

- **画面の取り込みを禁止している書籍アプリでは使えません。** 画面が真っ黒に取り込まれるため、その場合は「取り込みを禁止している」と表示します。
- 手書き風の特殊なフォントや、絵に溶け込んだ擬音は読み取れないことがあります。
- AI の訳の質はモデルに左右されます。小さなモデルは訳を取りこぼすことがあり、その行は機械翻訳になります。
- 横組みで表示します。

## ビルド

```
./gradlew :core:test          # 組み分け・英文整形・組版・ページ送り検出・文脈つき翻訳・ページ保管庫
./gradlew :app:assembleDebug  # APK（Android SDK が必要）
```

Android SDK が見つからない環境では `:app` を外し、純 Kotlin の `:core` だけをビルドします。
GitHub Actions（`.github/workflows/fukidashi-android.yml`）がテストと APK のビルドを行い、APK を成果物として保存します。

| モジュール | 内容 |
|---|---|
| `core` | Android に依存しない処理。`BalloonGrouper` `ComicText` `JapaneseLayout` `PageChangeDetector` `StoryContext` `StoryPrompts` `StoryTranslator` `PageLibrary` |
| `app` | 画面の取り込み、ML Kit、MediaPipe LLM、ページめくり、オーバーレイ、設定画面 |
