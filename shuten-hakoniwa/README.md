# 酒呑童子の邸宅 — 箱庭

Three.js で作った、斜め上から見下ろす「箱庭」。画像・3D モデルは一切使わず、形・質感・人物・炎・霧まで全部コードで生成しています。

`index.html` は Three.js ごと 1 枚に埋め込んであるので、ダブルクリックで開けます（Google Fonts だけは任意で、無くても動きます）。

## 見どころ
- 白無地の空間に浮かぶ島。島の周りには小岩と薄い雲が漂い、全体がゆっくり浮き沈みします
- 寝殿造の邸宅（寝殿・対屋・渡殿・釣殿・鉄の門・築地塀）、池と太鼓橋、白砂の庭、紅葉と松
- 灯りは「グロー + 低く漂う霧のシェーダー（ランプの色を拾ってにじむ）+ ブルーム + 水面への映り込み」の重ね掛け
- 動き続けるもの: 酒呑童子の盃と酌をする女、呑む鬼、篝火を囲んで踊る鬼、太鼓、門番、見回り、酒樽運び、
  琴・洗濯・橋の散策をする女たち、錦鯉、鬼火、舞い散る紅葉、島の揺れ
- 酒呑童子は寝殿の壇に一人だけ。ときどき源頼光の一行（山伏姿・六人）が門から訪れ、寝殿に上がって酒宴ののち霧へ戻ります

## 操作
- ドラッグで回転 / ホイールで拡大縮小 / 右ドラッグ・二本指で移動
- 下のボタンで視点を切り替え（全景・真上・広間・池と灯り・門・島の下）
- 「屋根をかける／はずす」は寝殿の屋根の切り替え（既定は絵巻の「吹抜屋台」のように屋根なし）
- 「自動で回す」でゆっくり周回

## ビルド
```sh
npm install
npm run build   # src/ → index.html
```
構成: `src/island.js`（浮島）、`buildings.js`（建物と屋根）、`garden.js`（庭）、`fx.js`（霧・水・炎・鬼火など）、
`characters.js`（人物のリグとポーズ）、`world.js`（配置と台本）、`main.js`（描画・カメラ・UI）。
